# Catch duplicate first notices of loss

**Assigned:** Aisha Bello

An insured reports the same accident through the app, then calls to make sure
we got it. Two claims open, two adjusters assign, one insured gets two
different answers.

- Match on policy, loss date, and vehicle within a short window.
- Offer the caller the existing claim number rather than a new claim.
- Merge path for the duplicates already in the system
  (claims/auto-accidents/record-car-accident.feature.md).
